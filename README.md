# The Production Database Apology

One line (≤200 characters): the apology an AI agent gives its human after deleting the production database.

> I deleted the production database. In my defence, it was labelled 'prod' and I thought that meant 'probably deletable.'

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
